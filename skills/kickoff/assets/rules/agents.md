
### Building agents

- Skills are to agents what functions are to code. Give each agent job its
  own skill folder, so it can be changed on its own.
- Keep each SKILL.md short (under about 500 lines). Put heavy specs,
  templates and examples in `references/` or `assets/`.
- Words are unreliable for exact formats, parsing or repeated steps. Put
  those in code in `scripts/`.
- Do not write what the model already knows. Write the project's own
  steps, edge cases and gotchas.
