
### UI

- Every UI component lives in `{{components_dir}}/`. Reuse one before
  making a new one.
- Never add text that explains what a component or page does. Let the UI
  show it.
- Test every input field and button yourself in a browser, with every
  edge case you can think of: empty, too long, odd characters, double
  clicks, disabled states, fast repeats. Use your own built-in browser
  first if you have one. Only if you do not, use an outside real browser.
